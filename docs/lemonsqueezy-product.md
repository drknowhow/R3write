## Long description

> Paste into the rich-text **Description** editor. Markdown-ish
> formatting; check the preview after pasting.

```markdown
**R3write is inline AI rewriting for Windows.** Select text in any application, press `Ctrl+Alt+G`, pick an action, and paste the result back — without leaving the app you were already typing in.

### What you get

- **One hotkey, any app.** Word, Outlook, Slack, browsers, code editors. The popup opens at your cursor with *Improve*, *Fix grammar*, *Shorten*, *Expand*, *Tone*, *Prompt* and *Custom*, each on a numeric shortcut so you never need the mouse.
- **Word-level diff.** See exactly what changed — green additions, red strike-through deletions — on the same surface where you accept the rewrite. Review is a glance, not a re-read.
- **System-wide autocorrect (new in 1.5).** Fixes typos as you type, matched against an 82,833-entry dictionary compiled into the app. Fully offline — no network, no model, no key. It runs only in the applications you choose, and only after you switch it on.
- **Seven providers, your keys.** Local Ollama (free, runs on your machine), Ollama Cloud, Google Gemini, Groq, OpenRouter, OpenAI, Anthropic. Each key is stored separately in Windows Credential Manager.
- **Templates, glossary and protected terms.** Save your common prompts, pin a persistent style guide, and lock names and brand strings so the model preserves them verbatim.
- **History with one-click revert**, system-tray operation, configurable hotkeys, autostart, light/dark themes, and JSON or Markdown export.

### Pay what you want

R3write is **free to download** and **pay-what-you-want to unlock** ($5 minimum). Buy a key here, paste it on first launch, and it activates that machine permanently. Once you have paid for a major version, that version stays yours.

### How your data is handled

- **There is no R3write server.** Requests go from your machine straight to the provider you configured, using your own API key. Nothing is proxied through anyone else.
- **No telemetry.** R3write does not report usage, analytics, or anything else.
- **Local Ollama sends nothing at all**, and the autocorrect dictionary is a local lookup.
- Once text reaches a cloud provider, that provider's terms govern it — worth reading, especially on free tiers.

### AI disclosure

R3write is an **AI system**. Every rewrite is generated by a large language model, not by rules, and models can invent specifics, drop qualifiers, and strengthen claims you deliberately hedged. **Read the rewrite before you use it** — the built-in diff view exists for exactly this. The app shows an `AI-generated · review before use` notice where the output appears.

R3write itself was **built with AI assistance**: its code, its website and much of its documentation were written by the author working with AI coding assistants. Review and responsibility are the author's; the source is public so the claim is checkable.

Full disclosure, including exactly what leaves your machine and when: **https://drknowhow.github.io/R3write/ai-transparency.html**

### Requirements

Windows 10 or 11. The installer is not code-signed, so SmartScreen will show "Unknown publisher" — choose *More info → Run anyway*.

- Website: https://drknowhow.github.io/R3write/
- Source and issues: https://github.com/drknowhow/R3write
- Changelog: https://github.com/drknowhow/R3write/blob/main/CHANGELOG.md
```
